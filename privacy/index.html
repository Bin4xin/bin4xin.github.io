隐私政策与 Cookie 偏好

构建时间：2026年08月12日 © 哨兵 (SENTINEL SECURITY, LAB) Web ver 3.2.0

1. 隐私承诺

欢迎访问 © 哨兵（https://bin4xin.github.io）。本站由哨兵安全实验室支持创办。我们高度重视您的个人隐私与数据安全，本博客为非商业性技术实验室站点，遵循最小化收集原则，不强制要求用户注册、登录或提供敏感的个人身份信息。

2. 技术栈与第三方服务

为了保障站点的安全性、访问速度与稳定性，本站点使用了以下技术架构及服务：

GitHub Pages 托管服务

本站源码托管于 GitHub，并通过 GitHub Actions (分支: main) 自动化构建静态文件。GitHub 可能会根据其隐私政策收集必要的服务器连接日志（如 IP 地址）。

Cloudflare CDN 网络加速

提供全球内容分发网络（CDN）服务，配合静态资源图床（https://image.isisy.com），提升访问速度并优化全球访问体验。

Cloudflare WAF 安全防护

网站防护防火墙（WAF），用于实时检测并防御恶意请求、Bot 抓取和 DDoS 攻击，确保实验室站点的正常运行。

Jekyll | MD 静态生成

基于 Jekyll :
代码高亮: rouge, Markdown
解析器: kramdown 构建。 纯静态 HTML 输出，不存在后端数据库收集与存储您的个人隐私数据。

3. Cookie 偏好与管理

Cookie 是保存在您浏览器上的小型文本文件。本博客仅使用维持基本功能与安全防护所必需的 Cookie，不包含广告追踪类 Cookie。

必要的安全与性能 Cookie (Strictly Necessary)

由 Cloudflare (例如 __cf_bm) 等服务自动设定，
用于区分真实访问者与恶意 Bot，确保 WAF 安全策略生效。

强制开启

功能性与偏好 Cookie (Functional)

用于记录您的主题模式偏好（如暗黑 / 亮色模式切换）及卡片通知的关闭状态。
