## 技战法概述

实战化攻防演练（如 HW 行动）是检验企业网络安全防护能力的重要手段。专业的攻击队伍（红队）对企业目标系统进行真实的渗透攻击，企业防守方（蓝队）需要在限定时间内发现、研判和处置攻击行为。

### 挑战

- 攻击手段高度接近实战：0day 漏洞利用、社工攻击、供应链投毒
- 7×24 小时持续值守
- 安全设备告警量在演练期间大幅增加
- 企业内部安全团队人员不足、技能参差不齐

### 三阶段技战法

| 阶段 | 名称 | 关键目标 |
|------|------|----------|
| 阶段一 | 演练前备战 | 资产梳理、风险排查、防守方案制定和团队组织 |
| 阶段二 | 演练中实战 | 标准化作战流程：实时监控、告警研判、攻击确认和应急处置 |
| 阶段三 | 演练后复盘 | 全面复盘，总结经验教训，提升防护能力 |

### 红队典型攻击手段

| 手段 | 说明 |
|------|------|
| 0day 漏洞利用 | Web / 中间件 / 应用未知漏洞 |
| 社工攻击 | 鱼叉式钓鱼 / 水坑攻击 |
| 供应链投毒 | 第三方组件 / 供应商通道 |
| 凭证攻击 | 密码喷洒 / 凭证填充 / 弱口令 |
| 组合攻击链 | 多阶段 / 多向量组合 |
