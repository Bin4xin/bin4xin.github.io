## 场景 2 — 阶段一：策略规则全量采集与分析

### 采集范围

| 设备类型 | 采集方式 | 说明 |
|----------|----------|------|
| 硬件防火墙 | API/SSH 自动采集 | Palo Alto / Fortinet / CheckPoint / 华为/深信服等 |
| 云安全组 | 云平台 API | AWS SG / 阿里云 SG / 腾讯云 SG / 华为云 |
| 云 WAF | API 采集 | 阿里云 WAF / 腾讯云 WAF / AWS WAF |
| 负载均衡 ACL | API 采集 | SLB/CLB/ALB 访问控制策略 |
| 主机防火墙 | Agent 采集 | iptables / Windows Firewall / 安全软件策略 |
| SDN 安全策略 | 控制器 API | 微分段/安全组策略 |

### 采集信息结构

| 字段 | 说明 |
|------|------|
| 规则 ID/序号 | 规则在策略中的位置编号 |
| 规则名称/描述 | 管理员添加的规则说明 |
| 源地址 | IP/网段/安全组/地址组 |
| 目的地址 | IP/网段/安全组/地址组 |
| 协议/端口 | TCP/UDP/ICMP 及端口范围 |
| 动作 | Allow / Deny / Drop |
| 生效方向 | Inbound / Outbound |
| 生效状态 | Enabled / Disabled |
| 创建时间 | 规则首次创建时间 |
| 最后命中时间 | 规则最近一次被匹配的时间 |
| 命中次数 | 规则累计匹配次数 |
| 关联策略 | 所属策略组/安全域 |
