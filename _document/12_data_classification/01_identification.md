## 场景 1 — 阶段一：数据资产识别与分类分级标签化

### 敏感数据自动发现

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 数据库扫描发现 | 全量数据库表/字段扫描，正则匹配 + 语义分析识别敏感字段，覆盖 MySQL/Oracle/PG/MongoDB |
| 2 | 文件系统扫描 | 文件服务器/NAS/对象存储扫描，文档内容解析 + 敏感关键词匹配，支持 Office/PDF/CSV/代码文件 |
| 3 | API 接口分析 | API 返回字段敏感度分析，请求/响应中敏感数据识别，API 文档自动解析标注 |
| 4 | 日志与备份排查 | 应用日志中敏感数据残留排查，备份数据敏感内容扫描，测试环境生产数据检查 |
| 5 | SaaS/云平台扫描 | 云端数据存储扫描，SaaS 平台数据分类检查，多云统一视图 |

### 识别技术与规则引擎

| 技术 | 说明 | 准确率 |
|------|------|--------|
| 正则规则匹配 | 身份证号/手机号/银行卡/邮箱/车牌号/社保号/护照号 | 95% |
| NLP 语义分析 | 基于 AI 模型的语义级识别，理解上下文含义，降低误报 | 85% |
| 元数据标签 | 字段名/表名/目录名推断，如 `user_idcard` → 身份证号 | 90% |
| 数据指纹匹配 | 已知敏感数据的哈希指纹，精确匹配已泄露数据样本 | 98% |
| 机器学习分类 | 训练数据分类模型，自动识别新型敏感数据模式 | 82% |

### 数据分类分级体系

| 等级 | 名称 | 说明 | 保护要求 |
|------|------|------|----------|
| L4 | 核心数据 · 极敏感 | 国家秘密/核心商业秘密/未公开财务 | 加密存储 + 严格访问控制 + 禁止外发 |
| L3 | 重要数据 · 高敏感 | 客户个人信息/交易记录/源代码 | 加密存储 + MFA + 审批外发 + DLP |
| L2 | 内部数据 · 中敏感 | 内部通讯录/组织架构/内部文档 | 访问控制 + 内部流转 + 审批外发 |
| L1 | 公开数据 · 低敏感 | 官网信息/产品手册/公开公告 | 无需特殊保护 |

### 数据分类示例

| 分类 | 等级 | 典型数据 |
|------|------|----------|
| 个人身份信息 | L4 | 身份证号/护照/生物特征 |
| 金融账户 | L4 | 银行卡号/支付密码/交易记录 |
| 健康医疗 | L3 | 病历/诊断/处方/基因数据 |
| 交易记录 | L3 | 订单/合同/发票/报价 |
| 员工信息 | L2 | 工资/绩效/考勤/通讯录 |
| 内部文档 | L2 | 会议纪要/内部报告/技术文档 |

### 自动化标签维度

| 维度 | 说明 |
|------|------|
| 数据分类 | 个人身份/金融/健康/商业/技术，基于数据内容和业务含义 |
| 敏感等级 | L4 极敏感/L3 高敏感/L2 中敏感/L1 低，基于泄露危害程度自动评估 |
| 业务归属 | 所属业务系统/部门/负责人，CMDB/数据目录自动关联 |
| 存储位置 | 数据库/文件/云端/SaaS，具体实例/表/字段/路径 |
| 合规要求 | 个人信息保护法/GDPR/PCI DSS，标注适用的法规和保护要求 |
