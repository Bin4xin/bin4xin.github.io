## 技战法概述

《中华人民共和国数据安全法》明确要求企业建立数据分类分级保护制度，根据数据的重要程度和一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护。企业在完成数据分类分级后，面临的核心挑战是如何对敏感数据的流转进行持续监控，确保敏感数据在采集、存储、使用、加工、传输、提供、公开等各环节中的安全可控。

敏感数据流转的风险主要体现在：数据在流转过程中可能超出授权范围被访问或使用；敏感数据可能通过非授权的渠道（如个人邮箱、公共网盘、即时通讯工具等）被外发；数据在不同系统间流转时，安全保护级别可能降低；数据在与第三方共享时，缺乏有效的监控和审计手段。

### 三阶段技战法

| 阶段 | 名称 | 关键目标 |
|------|------|----------|
| 阶段一 | 数据资产识别与分类分级标签化 | 完成敏感数据的识别和分类分级标签的自动化标注 |
| 阶段二 | 数据流转路径映射与监控部署 | 梳理敏感数据的流转路径，部署数据流转监控能力 |
| 阶段三 | 风险预警与处置闭环 | 建立敏感数据流转的风险预警机制和处置流程 |

### 数据生命周期七环节

| 环节 | 风险 |
|------|------|
| 采集 | 过量采集/未告知采集 |
| 存储 | 明文存储/权限过大 |
| 使用 | 越权访问/非授权使用 |
| 加工 | 脱敏不足/数据残留 |
| 传输 | 明文外发/非授权渠道 |
| 提供 | 第三方失控/缺乏审计 |
| 销毁 | 残留未清/不可恢复性 |
