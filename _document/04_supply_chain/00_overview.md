## 技战法概述

供应链攻击通过受信任的供应链通道渗透，传统安全防线形同虚设。攻击入口包括第三方依赖投毒、CI/CD 管道劫持、容器镜像投毒和供应商远程接入等。

### 四阶段技战法

| 阶段 | 名称 | 关键目标 |
|------|------|----------|
| 阶段一 | 攻击发现与威胁确认 | 确认供应链攻击并评估影响范围 |
| 阶段二 | 紧急隔离与业务切换 | 切断攻击通道，业务切换到安全环境 |
| 阶段三 | 全面排查与清除 | 全量排查受影响系统，彻底清除后门 |
| 阶段四 | 环境重建与加固 | 全新环境重建，建立供应链安全机制 |

### 攻击入口点

| 入口 | 说明 |
|------|------|
| 第三方依赖投毒 | npm / pip / Maven 恶意包，typosquatting / dependency confusion |
| CI/CD 管道劫持 | 构建服务器被入侵，篡改构建脚本 / 注入恶意步骤 |
| 容器镜像投毒 | 基础镜像含后门，Docker Hub 恶意镜像 |
| 供应商远程接入 | VPN / 堡垒机供应商账户被控 |

### 核心特征

- **隐蔽性极强**：通过合法渠道分发，签名完整，WAF / 防火墙 / EDR 均不告警
- **信任链利用**：代码签名 / 构建验证均通过
- **潜伏期长**：数周至数月才激活后门（SolarWinds 潜伏 9 个月）
- **影响面广**：一次投毒影响所有下游用户
