## 场景 4 — 阶段三：影响评估与处置建议

### 泄露数据影响评估

| 数据类型 | 数量 | 敏感级别 | 合规风险 |
|----------|------|----------|----------|
| 客户个人信息 | 52,000 条 | 极高 (PII) | 个人信息保护法 |
| 支付信息 | 部分 | 中 | PCI DSS |
| 商业合同与报价 | 230 份 | 高（商业秘密） | 反不正当竞争法 |

**影响严重度：**

| 维度 | 等级 |
|------|------|
| 法律风险 | 极高 |
| 声誉风险 | 高 |
| 商业风险 | 高 |
| 监管处罚 | 极高 |

### 法律合规评估

| 法规 | 要求 |
|------|------|
| 个人信息保护法 | 需在 72h 内向监管部门报告，需通知受影响个人 |
| 数据安全法 | 评估是否触发数据安全审查 |
| 商业秘密保护 | 可依法追究刑事责任 |
| 劳动合同 / 保密协议 | 追究违约责任和赔偿 |

### 处置建议

| 优先级 | 动作 | 说明 |
|--------|------|------|
| 🔴 立即处置 | 终止劳动关系 | 收回所有权限和设备，要求删除公司数据 |
| 🟠 法律行动 | 公安报案 | 侵犯商业秘密罪，委托律师发函 |
| 🟡 监管报告 | 网信部门报告 | 个人信息泄露事件，配合监管部门调查 |
| 🔵 客户通知 | 通知受影响用户 | 提供信用监控 / 身份保护服务 |
| 🟢 技术止损 | 暗网下架 | 追踪数据二次传播并阻断 |

### 证据链报告结构

1. 事件概述与时间线
2. 泄露数据范围与敏感度评估
3. 涉案人员信息与行为分析
4. 数据流转路径完整还原
5. 电子证据清单与哈希值
6. 证据保管链记录
7. 法律合规影响评估
8. 处置建议与改进措施
