## 场景 1 — 第三方供应商威胁模型与风险全景

### 供应商访问与风险模型
企业(目标系统/数据) → 访问权限(VPN/API/数据) → 供应商(产品/服务/人员) → 攻击者(入侵供应商) → 企业被控(数据泄露/中断)

text

> 攻击者利用供应商作为跳板，通过合法通道渗透企业

### 高风险供应商类型

| 类型 | 说明 |
|------|------|
| SaaS 应用供应商 | CRM/ERP/HR/办公协作等，持有企业业务数据和用户数据 |
| 云基础设施供应商 | IaaS/PaaS 服务商，掌控企业全部云端资产 |
| 外包开发供应商 | 软件外包/驻场开发人员，拥有代码库和内网访问权限 |
| 数据处理供应商 | 数据分析/营销/客服外包，接触大量客户个人信息 |
| 安全服务供应商 | MSSP/SOC 外包/渗透测试，拥有安全设备和日志访问权 |
| 技术组件供应商 | SDK/中间件/开源组件，代码层面的深度集成 |

### 攻击时间线

| 阶段 | 时间 | 动作 | 说明 |
|------|------|------|------|
| 侦察 | T+0 | 攻击者侦查供应商 | 识别供应商员工/系统/漏洞 |
| 入侵 | T+3d | 入侵供应商系统 | 钓鱼/漏洞/弱口令 |
| 横移 | T+7d | 获取企业访问凭证 | VPN 账号/API Key/证书 |
| 渗透 | T+10d | 通过合法通道进入企业 | 使用供应商的合法接入方式 |
| 目标 | T+15d | 数据窃取/业务中断 | 核心数据泄露/系统被控 |
