## 场景 3 — 阶段二：合同约束与安全基线约定

### 必备安全合同条款

| 序号 | 条款 | 说明 |
|------|------|------|
| 1 | 数据保护条款 | 数据分类/加密要求/存储位置，数据不得用于约定外目的，合作结束后的数据销毁义务 |
| 2 | 访问控制条款 | 最小权限原则/权限审批流程，多因素认证/特权账号管理，访问日志保留与审计权 |
| 3 | 安全事件通报条款 | 事件通报时限（如 24h 内），通报内容/响应协同机制，取证配合义务 |
| 4 | 审计权条款 | 企业有权对供应商安全审计，现场检查/远程评估权，第三方审计报告要求 |
| 5 | 违约与终止条款 | 安全违规的违约责任，严重安全事件的合同终止权，赔偿机制和上限 |
| 6 | 分包管理条款 | 分包商需经企业审批，分包商安全要求不低于供应商，供应链安全责任传递 |

### 安全基线要求

| 项目 | 要求 |
|------|------|
| 加密要求 | 传输加密: TLS 1.2+，存储加密: AES-256，密钥管理: HSM/KMS |
| 认证要求 | MFA 强制启用，密码策略: ≥12 位 + 复杂度，会话超时: ≤30min |
| 日志要求 | 操作日志保留 ≥ 6 个月，安全事件日志实时同步，日志不可篡改/防删除 |
| 漏洞管理 | 高危漏洞 72h 内修复，定期渗透测试(每年 ≥ 1 次)，安全补丁及时更新 |
| 人员要求 | 接触敏感数据人员背景审查，年度安全意识培训，离职权限即时回收 |

### 供应商访问权限管理

| 步骤 | 说明 |
|------|------|
| 1. 权限申请与审批 | 供应商人员需提交权限申请，企业方主管 + 安全部门双重审批 |
| 2. 最小权限分配 | 仅授予业务所需的最小权限，按项目/时间段精确控制 |
| 3. 独立账号体系 | 供应商使用独立命名空间，如 `vnd_zhangsan@company.com` |
| 4. 访问行为监控 | 供应商账号操作全面审计，异常行为实时告警 |
| 5. 定期权限回收 | 项目结束即时回收权限，季度权限复核清理 |

### 安全 SLA 约定

| 项目 | 要求 | 罚则 |
|------|------|------|
| 事件通报 | 24h 内 | 违约金 |
| 高危漏洞修复 | 72h 内 | 服务降级 |
| 数据销毁 | 终止后 30 天 | 违约金 |
| 安全审计配合 | 年度 ≥ 1 次 | 合同续签否决 |
| 服务可用性 | 99.9% | SLA 赔偿 |
