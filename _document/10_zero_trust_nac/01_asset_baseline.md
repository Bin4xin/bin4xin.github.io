## 场景 1 — 阶段一：终端资产清查与合规基线制定

### 终端资产全面清查

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 网络扫描发现 | 主动扫描企业网络中所有活跃终端，Nmap/资产探测工具识别 OS/端口/服务 |
| 2 | EDR Agent 采集 | 终端 Agent 上报硬件/软件/配置信息，补丁版本/安全软件/加密状态 |
| 3 | MDM 设备管理 | 移动设备管理平台采集 BYOD 设备，设备型号/OS 版本/越狱/root 状态 |
| 4 | 资产标签与归属 | 每台终端关联责任人/部门/业务等级，区分企业设备 vs 个人设备 (BYOD) |
| 5 | 资产台账建立 | CMDB 统一管理 + 自动化更新，资产生命周期状态实时维护 |

### 终端安全合规基线

| 项目 | 要求 |
|------|------|
| 操作系统安全 | OS 版本 ≥ 最低要求，补丁 72h 内更新，磁盘加密(BitLocker/FileVault)已启用 |
| 安全软件 | EDR Agent 在线运行，病毒库已更新，防火墙已启用且策略合规 |
| 身份认证 | 开机密码 ≥ 12 位，屏保锁 ≤ 5min，MFA 已绑定，生物识别可选 |
| 软件管理 | 禁止安装未授权软件，禁止破解工具，浏览器版本 ≥ 最低要求 |
| 网络配置 | DNS 配置正确，代理策略合规，禁止开放远程桌面到公网 |
| BYOD 特殊要求 | MDM Profile 已安装，工作容器隔离，越狱/root 设备禁止访问企业资源 |
