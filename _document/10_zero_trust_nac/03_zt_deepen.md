## 场景 3 — 阶段三：零信任策略深化与持续运营

### 微隔离与应用级授权

| 能力 | 说明 |
|------|------|
| 网络微隔离 | 将网络从 VLAN 粒度细化到应用/服务级粒度的微隔离 |
| 应用级授权 | 从网络级访问控制转向单应用级细粒度授权 (SDP) |
| 持续认证 | 登录后持续评估用户行为，风险变化时要求二次认证 |
| 动态授权 | 基于实时风险评分动态调整权限，高风险 → 收缩权限，低风险 → 维持 |
| 行为监控 | UEBA 持续监控访问行为，异常行为触发重新认证/降权 |

### 零信任深化路线图

| 等级 | 名称 | 说明 |
|------|------|------|
| L1 | 网络准入控制 | 802.1X + 合规检查 + 隔离修复，覆盖所有企业办公网络接入 |
| L2 | 远程 ZTNA 接入 | ZTNA 替代传统 VPN，应用级细粒度授权，按需最小权限 |
| L3 | 身份为中心的访问 | 统一身份平台 + SSO + MFA，设备信任 + 用户信任双因子 |
| L4 | 微隔离与数据保护 | 应用间微隔离 + 数据分类标签，数据访问 DLP 实时监控 |
| L5 | 持续自适应信任 | UEBA + AI 驱动风险评估，实时动态信任评分，自适应授权 |

### 持续运营机制

| 机制 | 说明 |
|------|------|
| 合规率持续监控 | 日/周/月合规率趋势追踪，不合规 Top10 原因分析 |
| 策略定期评审 | 季度策略有效性评估，业务变化驱动策略更新 |
| 指标度量体系 | MTTD/MTTR/接入成功率，策略命中率/误拦率 |
| 用户培训与体验 | 准入流程用户培训，自助修复体验优化 |
| 应急预案更新 | NAC 故障应急方案，ZTNA 不可用时的降级策略 |

### 零信任成熟度评估

| 维度 | 当前 | 目标 |
|------|------|------|
| 身份安全 | L3 | L4+ |
| 终端安全 | L2.5 | L4 |
| 网络准入 | L3.5 | L5 |
| 应用授权 | L1.5 | L4 |
| 数据保护 | L2 | L4 |
| 持续监控 | L2.5 | L5 |

**成熟度等级：** L1 初始(部分实施) → L2 基础(覆盖 60%) → L3 标准(全面覆盖) → L4 优化(持续自适应) → L5 高级(AI 驱动)
